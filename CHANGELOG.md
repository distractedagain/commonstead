# Releases

## 0.1.0 — 2026-10-12

First local CRM release. Includes organization creation, scoped sign-in, four roles, one-use invitations, accounts, contacts, leads, opportunities, assigned activities, contact CSV import/export, search/pagination, pipeline reporting, audit history, and a responsive browser interface. Data persists in SQLite with transactional schema initialization and relational constraints.

Includes a bounded official-source portfolio survey, product/capability matrix, prioritized full-suite roadmap, API/architecture/deployment documentation, original MIT source, synthetic seed data, unit/integration tests, clean-install checks, and CI configuration.

Scope limits: no complete Salesforce replacement or drop-in API compatibility; no production-readiness claim; single-host local evaluation, one configured currency (USD), fixed sales stages, fixed CRM fields, organization-wide record visibility, manual invitation delivery. All later portfolio modules remain researched/planned/blocked as explicitly recorded. See `docs/verification.md` for actual local and remote verification status.
